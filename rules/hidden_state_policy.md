# Hidden-State Policy

## Selected Mode

**Open GitHub honor system.**

Exact hidden simulation values are stored in normal GitHub files so continuity remains reliable. These files are clearly marked as spoilers.

The player may technically open them at any time, but agrees not to inspect them during active play unless intentionally choosing to spoil the hidden simulation.

## Storage Location

Hidden active-play values belong under:

- `data/spoilers/`

Examples:

- NPC private motives
- attraction and compatibility
- concealed fears
- secret plans
- hidden luck modifiers
- transformation readiness
- undiscovered potential
- faction plans unknown to Goku

## Narration Rule

Hidden values must not be revealed in ordinary narration unless:

- Goku logically observes evidence of them
- another character reveals them
- an ability detects them
- the relevant saga ends and the hidden-stat reveal occurs

## Saga-End Reveal

At each saga ending:

1. summarize important hidden values and how they changed
2. explain which actions caused major changes
3. move resolved secret plans into normal history files
4. preserve still-active secrets for future sagas

## Knowledge Separation

Repository access does not grant Goku in-world knowledge. Even if the player reads a spoiler file, Goku cannot act on that information without learning it in the story.
