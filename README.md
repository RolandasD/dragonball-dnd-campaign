# Dragon Ball D&D Campaign

Persistent campaign brain for a Dragon Ball what-if D&D/chat RPG campaign.

## Core concept

A Goku-only Dragon Ball campaign that follows the canon skeleton unless player choices logically break it.

The repo exists to prevent continuity mistakes by tracking:

- current save state
- canon pillars
- divergences
- power levels
- character stats
- relationships
- hidden DM systems
- session logs
- open plot threads

## Play workflow

1. Before each session, read `campaign/current_state.md`, `data/flags.json`, `data/power_levels.csv`, and the current saga file.
2. Run the session in chat.
3. During major scene changes, update state files.
4. At session end, create/update a session log and refresh current state.

## Current campaign settings

- Scope: Dragon Ball, Z, Super, GT, Daima, movies, and what-if arcs.
- Canon: canon skeleton stays unless major divergences logically break it.
- Power levels: hard rule; big gaps matter heavily.
- Difficulty: challenging.
- Humor: TFS flavor, but not full clown mode.
- Player control: Goku only.
- Spoilers: everything visible.
- Combat: mostly story combat.
- Training: detailed RPG system.
- Death: deaths matter; Dragon Balls are limited.
- Hidden DM systems: heavy.
- Cards: no cards.
- Session style: long chaos sessions.
- Free choice: always include an open-ended option.
