# Dragon Ball D&D Campaign

Persistent campaign brain for a Goku-only Dragon Ball what-if chat RPG.

## Core concept

A long-running campaign that begins shortly before Bulma meets Kid Goku. Canon provides gravity and structure, but logical divergences, dynamic growth, original villains, and a living simulated world determine the actual timeline.

## Primary operational files

Before every campaign response, read and cross-check:

1. `rules/campaign_master_profile.md`
2. `campaign/current_state.md`
3. `data/flags.json`
4. `data/power_levels.csv`
5. `data/relationships.csv`
6. `data/divergence_tracker.md`
7. the current saga scenario map
8. any character files relevant to the active scene

## Play workflow

1. Run a strict consistency check before each campaign reply.
2. Resolve the player's action using locked rules, current state, character knowledge, and logical consequences.
3. Update GitHub after every turn.
4. Update current state, flags, power levels, relationships, divergence tracking, and relevant character records whenever they change.
5. Stop and correct contradictions immediately.
6. Preserve alternate timelines and deprecated plans rather than deleting history.

## Current campaign settings

- Scope: Dragon Ball, Z, Super, Daima, GT, TV specials, selected filler, nearly all later movies, and original campaign material.
- Excluded by default: original Dragon Ball theatrical retellings, game-original arcs, Heroes, and Xenoverse material.
- Canon: canon skeleton stays unless logical divergences break or replace it.
- Power levels: hard rule; massive gaps matter heavily.
- Difficulty: challenging, but important characters have limited protection from random meaningless deaths.
- Humor: TFS flavor, but scenes remain short, simple, and mostly serious.
- Player control: Goku only.
- Stats: true power levels are visible; combat stamina, ki, and exact damage percentages remain hidden.
- Training: deep RPG simulation with detailed technique mastery.
- World simulation: autonomous NPCs, relationships, factions, planets, Frieza Force, Galactic Patrol, fame, and family development.
- Death: meaningful, while Goku is not permanently removed during ordinary play because revival remains available.
- GitHub: player-readable, updated every turn, with strict consistency checks.
- Long-term goal: build an enormous living universe where Dragon Ball canon is only the beginning.
